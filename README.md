# Mine Rehabilitation Monitoring System

A software-based remote sensing system for monitoring vegetation recovery and land-cover changes in reclaimed mining areas using freely available Sentinel-2 satellite imagery.

## Objective

To develop a low-cost prototype that uses multi-temporal satellite data, vegetation indices, geospatial analysis, and change detection to support monitoring of mine reclamation and rehabilitation.

## Study Area

Barora, Dhanbad, Jharkhand

## Current Status

Project setup and study-area/data validation in progress.
